# CineMory 계정 삭제 요청

CineMory 계정과 관련 데이터는 아래 두 방법 중 하나로 삭제할 수 있습니다.

## 방법 1. 앱에서 바로 삭제 (권장)

1. CineMory 앱 → **마이페이지** → 오른쪽 위 **설정**
2. 맨 아래 **회원 탈퇴**
3. 안내를 확인하고 탈퇴 (이메일로 가입했다면 비밀번호 입력)

탈퇴하면 **즉시** 삭제됩니다.

## 방법 2. 앱을 쓸 수 없을 때 — 이메일로 요청

**cadmin295@gmail.com** 으로 아래 내용을 보내 주세요.

- 제목: `[계정 삭제 요청]`
- 가입한 이메일 주소
- 가입 방법(이메일 / 카카오 / 구글)

가입한 이메일 주소에서 보내 주셔야 본인 확인이 됩니다. 다른 주소에서 보내시면 확인 메일을 다시 드립니다. 확인 후 **7일 안에** 삭제하고 결과를 회신합니다.

## 삭제되는 데이터

- 계정 정보(이메일, 비밀번호, 닉네임, 로그인 연결 정보)
- 시청 기록, 별점, 메모, 리뷰, 보고 싶은 영화, 컬렉션
- 프로필(자기소개, 인생 영화, 프로필 사진, 커버 이미지)
- 팔로우·팔로워 관계

## 보관되는 데이터

- 서버 백업본에 포함된 데이터는 백업일로부터 **최대 7일** 뒤 자동 삭제됩니다.
- 관리자 처리 기록에는 회원 번호만 남고 이메일 등 개인정보는 남지 않습니다(1년 보관).

자세한 내용은 [개인정보처리방침](/privacy)을 확인해 주세요.
