# CineMory 개인정보처리방침

CineMory(이하 "서비스")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 이와 관련한 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

- 운영자: 한인웅 (개인 개발자)
- 시행일: [시행일]

## 1. 처리하는 개인정보의 항목과 목적

| 구분 | 항목 | 목적 |
|---|---|---|
| 이메일 회원가입 | (필수) 이메일, 비밀번호, 닉네임 | 회원 식별, 로그인, 비밀번호 재설정 안내 |
| 카카오·구글 로그인 | (필수) 이메일, 로그인 서비스가 발급한 회원 식별값 | 회원 식별, 로그인. **카카오·구글의 이름(닉네임)과 프로필 사진은 받지 않습니다** |
| 서비스 이용 중 이용자가 입력하는 정보 | 시청 기록(관람일, 관람 방식·장소, OTT 서비스, 별점, 나만 보는 메모), 리뷰, 보고 싶은 영화, 컬렉션, 팔로우 관계, 프로필(닉네임, 자기소개, 인생 영화, 프로필 사진, 커버 이미지), 공개 범위 설정 | 기록·분석·추천 기능 제공, 공개 범위에 따른 소셜 기능 제공 |
| 자연어 추천 검색 | 이용자가 입력한 검색 문장 | 문장의 의미를 분석해 영화를 추천 (저장하지 않으며, 짧은 시간 동안 결과를 임시 보관합니다 — 5절 참고) |
| 내 주변 극장 찾기 | 기기의 현재 위치(위도·경도, 약 100m 단위로 줄여 전송) | 가까운 극장 목록과 지도 표시. **이용자가 그 기능을 쓸 때만** 기기 권한 동의를 받아 수집하며, 계정이나 서버 기록에 저장하지 않습니다 |
| 자동으로 생성되는 정보 | 접속 IP 주소, 접속 일시, 요청 주소(URL — 위치가 포함된 요청은 기록하지 않음), 기기·앱 정보(User-Agent), 로그인 유지용 토큰, 약관 동의 시각 | 보안(부정 이용 방지·접속 제한), 장애 대응, 동의 사실 확인 |

- 비밀번호와 로그인 유지용 토큰은 원문을 저장하지 않고 복원할 수 없는 형태(해시)로만 저장합니다.
- 서비스는 광고·마케팅 목적으로 개인정보를 이용하지 않으며, 이용 행태 분석 도구(광고 식별자, 분석 SDK)를 쓰지 않습니다.

## 2. 처리 및 보유 기간

| 항목 | 보유 기간 |
|---|---|
| 회원 정보와 이용자가 입력한 모든 정보 | **회원 탈퇴 시 즉시 삭제** |
| 서버 백업본에 포함된 정보 | 백업일로부터 **최대 7일** 후 자동 삭제 (탈퇴 후에도 이 기간 동안 백업본에 남을 수 있습니다) |
| 접속 기록(IP, 일시, 요청 주소) | 기록일로부터 **14일** 후 자동 삭제 |
| 비밀번호 재설정 링크 | 발급 후 30분 동안만 유효 |
| 로그인 유지 기록(토큰 해시) | 만료 후 90일 뒤 자동 삭제 |
| 내 기록 내보내기 링크 | 발급 후 10분, 한 번만 사용 가능 |
| 가입 시 약관 동의 시각 | 회원 탈퇴 시 즉시 삭제 |
| 업로드한 이미지(프로필 사진, 커버) | 교체·삭제·탈퇴 시 즉시 삭제. 전송 속도를 위해 콘텐츠 전송망(CDN)에 남은 복사본은 일정 시간 후 자동 만료되며, 그동안에도 서비스 안에서는 더 이상 표시되지 않습니다 |
| 관리자의 회원 정보 열람·처리 기록 | 1년 (이용자 정보는 회원 번호만 남고 이메일 등은 남지 않습니다) |

## 3. 개인정보의 파기 절차와 방법

- 탈퇴를 요청하면 계정과 이용자가 입력한 정보를 데이터베이스에서 즉시 삭제하고, 업로드한 이미지 파일도 저장소에서 삭제합니다.
- 전자적 파일은 복구할 수 없는 방법으로 삭제하며, 종이 문서로 된 개인정보는 처리하지 않습니다.

## 4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 수사기관 등이 적법한 절차로 요구하는 경우는 예외로 합니다.

**서비스 안에서의 공개**: 이용자가 설정한 공개 범위(전체 공개 / 친구 공개 / 나만 보기)에 따라 기록·리뷰·컬렉션 등이 다른 이용자에게 보입니다. 새로 가입한 계정의 기본 공개 범위는 **친구 공개**(서로 팔로우한 이용자에게만 공개)이며, 프로필 수정 화면에서 언제든 바꿀 수 있습니다. "나만 보기"를 선택하면 다른 이용자에게는 닉네임과 프로필 사진만 보입니다. "나만 보는 메모"는 공개 범위와 관계없이 본인에게만 보입니다.

## 5. 개인정보 처리의 위탁 및 국외 이전

서비스 운영을 위해 아래 업체에 개인정보 처리를 맡기고 있습니다.

| 수탁자 | 위탁 업무 | 이전되는 항목 | 이전 국가 · 방법 · 시기 | 보유 기간 |
|---|---|---|---|---|
| Amazon Web Services, Inc. | 서버·데이터베이스 운영, 이미지 저장 | 1절의 모든 정보 | 대한민국(서울 리전)에 저장. 이미지 전송망(CloudFront)은 이용자와 가까운 해외 거점에 이미지 복사본을 임시 저장할 수 있음 · 네트워크 전송 · 서비스 이용 시 | 위탁 계약 종료 또는 2절의 기간까지 |
| Google LLC (Gmail) | 비밀번호 재설정 메일 발송 | 이메일 주소 | 미국 · 네트워크 전송 · 재설정 요청 시 | 메일 발송 후 Google의 정책에 따름 |
| Google LLC (Gemini API) | 자연어 추천 검색 문장의 의미 분석 | 검색 문장(계정 정보는 함께 보내지 않음) | 미국 · 네트워크 전송 · 검색 시 | [확인 필요: 유료 등급 사용 시 — 모델 개선에 쓰이지 않고 Google 정책상 짧은 기간 후 삭제] |

- 국외 이전을 원하지 않으면 해당 기능(비밀번호 재설정, 자연어 추천 검색)을 이용하지 않을 수 있습니다. 다만 비밀번호 재설정 메일은 그 기능에 필수입니다.
- 카카오 로그인·구글 로그인을 선택한 경우 로그인 과정은 각 회사의 개인정보처리방침이 적용됩니다.
- 극장 지도는 주식회사 카카오의 지도 서비스를 이용해 기기에서 표시합니다. 지도를 불러오는 과정에서 표시 영역에 대한 요청이 카카오로 전송될 수 있습니다.

## 6. 이용자의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

- **열람·수정**: 앱의 마이페이지·프로필 수정·설정 화면에서 직접 확인하고 고칠 수 있습니다.
- **내보내기**: 설정 → "내 기록 내보내기"에서 시청 기록·리뷰·보고 싶은 영화를 파일로 받을 수 있습니다.
- **처리 정지·삭제(탈퇴)**: 설정 → "회원 탈퇴"에서 즉시 탈퇴할 수 있습니다. 앱을 쓸 수 없는 경우 [계정 삭제 요청 페이지]에서 안내하는 방법(이메일)으로 요청할 수 있습니다.
- 위 권리는 개인정보 보호책임자에게 이메일로 요청해도 되며, 지체 없이 처리합니다.

## 7. 개인정보의 안전성 확보 조치

- 비밀번호는 bcrypt, 로그인 유지 토큰과 재설정 토큰은 SHA-256 해시로만 저장합니다.
- 모든 통신은 HTTPS로 암호화합니다.
- 업로드 이미지 저장소는 외부에서 직접 접근할 수 없게 막고, 전송망을 통해서만 제공합니다.
- 서버 접근 권한을 최소한으로 제한하고, 서버에 접근 키를 두지 않는 방식(역할 기반 권한)을 씁니다.
- 로그인·비밀번호 재설정 요청 횟수를 제한해 무단 대입 공격을 막습니다.
- 관리자의 회원 정보 열람·처리를 기록합니다.

## 8. 자동 수집 장치(쿠키 등)

앱은 쿠키를 쓰지 않습니다. 로그인 상태는 기기의 보안 저장소에 보관한 토큰으로 유지합니다.

## 9. 만 14세 미만 아동

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만은 가입할 수 없습니다. 가입할 때 만 14세 이상임을 확인받습니다.
